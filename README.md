# Простой файловый менеджер на Laravel

Веб-приложение для управления файлами с поддержкой папок, тегов и поиска. Проект разработан с акцентом на простоту: не используются Vite, сложные JS-фреймворки или избыточные зависимости.

## Функционал
- ✅ Аутентификация (регистрация и вход).
- ✅ Загрузка файлов (ограничение 5 МБ, только jpg, jpeg, png, pdf).
- ✅ Создание, переименование и удаление папок (вложенность поддерживается).
- ✅ Скачивание файлов и предварительный просмотр изображений.
- ✅ Поиск файлов по имени.
- ✅ Система тегов для удобной организации.
- ✅ Перемещение файлов между папками.
